# Windows 定时提醒器

一个本地运行的 Windows 桌面定时提醒工具。支持**一次性提醒**与**周期性提醒**（每天 / 每周 / 每月 / 每隔 N 分钟），**周期性提醒的最小时间粒度为 1 分钟**。数据保存在本机 SQLite 中，不联网、无账号。

## 功能特性

| 能力 | 说明 |
| --- | --- |
| 一次性提醒 | 指定「日期 + 时间」，触发一次后自动标记完成 |
| 每天 | 指定时刻，每天同一时间触发 |
| 每周 | 可多选星期几（周一至周日），指定时刻触发 |
| 每月 | 指定「几号 + 时刻」；当月不足该日时自动钳制到当月最后一天（如 31 号 → 2 月 28 号） |
| 间隔 | 每隔 N 分钟触发一次，N 最小为 1（支持 1–1440 分钟），以基准时间对齐 |
| 提前提醒 | 每个任务可单独设置提前 0–120 分钟提醒 |
| 提醒呈现 | 屏幕右下角置顶弹窗 + 系统提示音 + Windows 通知中心消息 |
| 稍后提醒 | 弹窗支持推迟 5 / 10 / 30 / 60 分钟（推迟本次，不影响既定计划） |
| 系统托盘 | 关闭窗口不退出，托盘菜单可打开主窗口、新建提醒、查看下一次提醒 |
| 开机自启 | 通过 HKCU 注册表项实现，无需管理员权限 |
| 错过补发 | 程序未运行时错过的提醒，在补发窗口内（默认 60 分钟）启动后补发一次并标注 |

## 环境要求

- Windows 10 / 11
- Python 3.10+（本机使用 Python 3.14.3，需带 tkinter）

## 安装与运行

```bat
:: 1. 创建虚拟环境并安装依赖（pystray / Pillow 仅用于托盘图标）
C:\Python314\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

:: 2. 运行（推荐双击 run.bat）
.venv\Scripts\pythonw.exe main.py
```

- `run.bat` —— 无控制台窗口启动（日常使用）
- `run-debug.bat` —— 带控制台输出，便于排查问题
- 命令行参数：`--hide`（启动后只驻留托盘）、`--no-tray`（不显示托盘图标）

## 使用说明

1. 主窗口点击「新建」，填写标题与提醒内容。
2. 选择提醒类型，下方参数面板会随之切换：
   - **一次性**：日期 `YYYY-MM-DD` + 时间，可点「今天 / 明天」快捷填充
   - **每天**：时间
   - **每周**：勾选星期 + 时间
   - **每月**：几号 + 时间
   - **间隔(分钟)**：间隔分钟数 + 起始时间（默认当前）
3. 底部实时显示「下一次提醒时间」预览，确认后保存。
4. 列表中可编辑、复制、停用/启用、删除任务；「立即测试」可立刻验证提醒效果。
5. 「选项设置」中配置提示音、弹窗、Windows 通知、托盘行为、开机自启与补发窗口。

## 数据存储

- 数据库：`data/timer.db`（SQLite，含 `tasks` 与 `history` 两张表）
- 设置：`data/settings.json`
- 打包为 exe 后自动切换到 `%LOCALAPPDATA%\TimerReminder\`

## 设计要点

1. **分钟粒度**：所有时间点统一截断到分钟（秒/微秒归零）。调度线程每秒轮询一次，但仅在「分钟数变化」或收到唤醒请求时执行全量扫描，CPU 开销可忽略。
2. **不会漏触发也不会重复触发**：触发后严格基于「上一次计划时间」推进下一次，保证单调递增；即便系统休眠后恢复，也只会补发最近的一次，不会连环弹出历史提醒。
3. **提前提醒只影响触发时刻**：判定条件使用 `next_run - advance_min`，推进计划仍以 `next_run` 为准，避免提前量累积漂移。
4. **线程模型**：调度与提示音/通知在后台线程，tkinter 组件全部在主线程创建，二者通过线程安全队列衔接。

## 常见问题

- **托盘图标没出现**：未安装 `pystray` / `Pillow` 时会自动降级，程序仍正常提醒，只是没有托盘入口。
- **Windows 通知没弹出**：通知中心需开启该应用的通知权限；弹窗与提示音不受影响。
- **修改系统时间或跨夏令时**：下次扫描会自动重算下一次触发时间。
